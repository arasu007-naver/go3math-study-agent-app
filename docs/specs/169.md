# 실황 수업 종료 후 나가면 학습장 시트 열기 (student-app)

## 배경과 목적
카드 #168에서 선생님이 '강의 종료'를 누르면 학생 화면에 **LiveClassClosedModal**(`src/kit/live-class/LiveClassClosedModal.tsx`)이 뜨게 했습니다. '확인'을 누르면 `goBack()`으로 캔버스 화면을 나갑니다.

지금 실황 수업을 나갈 때 학습장 시트를 여는 일은 **useSolveFinished**(`src/host/useSolveFinished.ts`)가 언마운트 때 합니다. 이 훅은 `openLiveStudyNoteOnLeave`(`src/host/liveStudyNoteOnLeave.ts`)를 부릅니다. 그런데 시트는 이번 방문에 학습 행동이 있었을 때만 열립니다(`acted`). 학습 행동은 답안 올리기(countSolved), 퀴즈 답안 제출(markActed), 개념 조회입니다. 그래서 수업이 끝났어도 학생이 아무 행동을 하지 않았으면 학습장이 뜨지 않습니다.

이번 변경으로, 수업 종료를 받은 뒤 캔버스 화면을 나가면 행동 여부와 상관없이 학습장 시트(**StudyNoteForm**: `src/kit/study-note/StudyNoteForm.tsx`, componentId `study_note`, mode `live`)가 반드시 열리게 합니다. 이전에 쓴 학습장이 있으면 그 내용이 채워진 채로 보여야 합니다.

대상 화면(docs/COMPONENTS.md 기준):
- **HotlineClassScreen**: `app/hotline-class.tsx` (`/hotline-class`)
- **TopicLiveClassScreen**: `app/topic-live-class.tsx` (`/topic-live-class`)

## 범위
### 하는 것
- **useSolveFinished**가 돌려주는 값에 `markClassClosed()`를 추가합니다. 이 함수를 부르면 내부 ref에 '수업 종료됨'이 기록됩니다.
- 두 화면의 구독 `onData`에서 `guide.action === LIVE_CLASS_CLOSED`를 처리하는 분기에서 `markClassClosed()`를 부릅니다. 지금 하는 `setLiveQuiz(null)`과 `setClosedVisible(true)`는 그대로 둡니다.
- 실황(live) 언마운트 경로에서는 `acted`를 `didAct || classClosed`로 넘깁니다. 수업 종료를 받은 뒤라면 어떤 경로로 나가도 학습장 시트가 열립니다. 경로는 '확인', 툴바 '나가기', 하드웨어 뒤로가기, 제스처를 모두 포함합니다.
- 이전 작성 내용 채우기는 StudyNoteForm의 지금 동작을 그대로 씁니다. 처음 값은 로컬 초안(`agent:studyNoteDraft:<taskId>`)이 있으면 초안, 없으면 서버에서 조회한 노트(`fetchers.fetchNote(taskId)` → `fromNote`)입니다. 이 동작을 확인하는 테스트가 없으면 추가합니다.

### 하지 않는 것
- LiveClassClosedModal의 문구, 버튼, 모양은 바꾸지 않습니다.
- 수업 종료를 받지 않은 상태에서 나가는 경우는 바꾸지 않습니다. 이때는 지금처럼 학습 행동이 있었을 때만 시트가 열립니다.
- NotebookScreen(`app/notebook.tsx`) 같은 self 캔버스의 `solve_finished` 흐름은 바꾸지 않습니다.
- StudyNoteForm의 양식, 저장 흐름, 초안·조회 우선순위는 바꾸지 않습니다.
- '나가기' 확인 Dialog(#164)와 퀴즈 처리(#47)는 바꾸지 않습니다.

## 변경할 동작
1. `useSolveFinished(a)`의 반환 타입을 `{ countSolved(): void; markActed(): void; markClassClosed(): void }`로 바꿉니다. `markClassClosed`는 `useCallback`으로 만들고 `closed.current = true`만 합니다.
2. 언마운트 cleanup의 live 분기에서 다음처럼 부릅니다.
   `openLiveStudyNoteOnLeave({ taskId, spec: liveSpec, acted: didAct || closed.current, activity, title })`
   - 그 밖의 처리(활동 기록 reset, owner 처리, live일 때 solve_finished를 보내지 않는 것, bumpStudyData)는 그대로 둡니다.
3. 두 화면의 LIVE_CLASS_CLOSED 분기에서 `markClassClosed()`를 부릅니다. 같은 메시지를 두 번 받아도 결과는 같습니다(멱등).
4. taskId가 없으면(이번 방문에 풀이를 올리지 않았고 `findLiveClassTaskId`도 아직 못 찾은 경우) 지금 `openLiveStudyNoteOnLeave`가 하듯 `ensureTaskId(undefined, liveSpec)`로 task를 확보합니다.
   - 실황 수업의 create는 그 수업(lesson_note)에 있는 내 task를 먼저 찾습니다. 그래서 이전에 쓴 학습장이 있는 task가 그대로 쓰입니다.
   - task를 확보하지 못하면 지금처럼 시트를 열지 않습니다.
5. 시트는 `showSheet('study_note', { taskId, mode: 'live', title })`로 엽니다. title은 HotlineClassScreen이 '선생님 실황 수업', TopicLiveClassScreen이 '주제 실황 수업'입니다. StudyNoteForm은 조회하는 동안 스켈레톤을 보이고, 끝나면 이전 노트의 달성률, 어려웠던 점, 메모를 채워 보입니다. 초안이 있으면 초안을 먼저 씁니다. 이전 노트가 있으면 저장 버튼 라벨은 '수정'입니다.

## API 계약
없음. 받는 메시지는 #168과 같습니다. guide content `{"action":"LIVE_CLASS_CLOSED", ...}`를 쓰며, 서버 변경은 없습니다.

## 수용 기준
1. `useSolveFinished`가 `markClassClosed` 함수를 돌려준다.
2. live kind(`hotline` 또는 `topic_live`, liveSpec 있음)에서 학습 행동 없이 `markClassClosed()`만 부르고 언마운트하면, `openLiveStudyNoteOnLeave`가 `acted: true`로 한 번 불린다. 결과로 `showSheet('study_note', { taskId, mode: 'live', title })`가 한 번 호출된다.
3. live kind에서 학습 행동도 없고 `markClassClosed()`도 부르지 않은 채 언마운트하면, 지금처럼 시트가 열리지 않는다(`acted: false`).
4. live kind에서 `markClassClosed()`를 부르고 언마운트해도 `solve_finished`는 emit되지 않는다.
5. HotlineClassScreen이 구독으로 content `{"action":"LIVE_CLASS_CLOSED","tutorId":"t1"}`를 받은 뒤 '확인'을 눌러 화면이 언마운트되면, 학습 행동이 없었어도 학습장 시트(study_note, mode 'live', title '선생님 실황 수업')가 열린다.
6. TopicLiveClassScreen이 `{"action":"LIVE_CLASS_CLOSED","topicId":5}`를 받은 뒤 언마운트되면, 학습 행동이 없었어도 학습장 시트(title '주제 실황 수업')가 열린다.
7. LIVE_CLASS_CLOSED를 두 번 받은 뒤 언마운트해도 시트는 한 번만 열린다.
8. taskId가 없는 상태에서 수업 종료 뒤 나가면 `ensureTaskId(undefined, liveSpec)`가 불리고, 그 결과 id로 시트가 열린다. `ensureTaskId`가 undefined를 돌려주면 시트가 열리지 않는다.
9. StudyNoteForm(mode 'live')에서 `fetchNote`가 기존 노트를 돌려주고 초안이 없으면, 노트의 달성률 칩이 선택되고, 어려웠던 점 칩이 선택되며, 메모 입력란에 노트 메모가 채워진다. 저장 버튼 라벨은 '수정'이다.
10. StudyNoteForm에서 초안이 있으면 서버 노트 대신 초안 값이 채워진다.
11. 기존 테스트(`__tests__/liveStudyNoteOnLeave.test.ts`, `__tests__/solveFinished.test.tsx`, `__tests__/studyNoteForm.test.tsx`, `__tests__/liveClassWaiting.test.tsx`, #164·#168 관련 테스트)가 통과한다. 테스트 기대값을 바꿔야 한다면 이번 변경 범위 안에서만 바꾼다.
12. 위 2~10을 검증하는 jest 테스트가 추가되고, `npx jest`와 `npx tsc --noEmit`이 통과한다.

## 가정
- '실황 수업 종료 후'는 LIVE_CLASS_CLOSED guide를 받은 뒤로 보았습니다. 이후 '확인'뿐 아니라 어떤 경로로 나가도 학습장을 엽니다.
- '학습장 작성 모달'은 지금 나갈 때 여는 학습장 시트(study_note, StudyNoteForm mode 'live')로 보았습니다.
- '이전 작성 사항'은 같은 수업 task의 서버 학습장 노트와 로컬 초안으로 보았습니다. 이를 채우는 동작은 StudyNoteForm에 이미 있으므로 고치지 않고 테스트로 확인합니다.
- 수업 종료 전에 나가는 경우의 동작(행동이 있을 때만 시트를 엶)은 그대로 둡니다.

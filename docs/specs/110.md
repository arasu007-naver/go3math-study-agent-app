# 2026 수능 기출 노출 — student-app

## 배경과 목적
2026년 11월 시행 수능 수학 문제가 입력되었으므로 학생이 앱에서 조회할 수 있게 합니다.

현재 동작:
- **ExamConstants**(`src/config/exam.constants.ts`)의 `thisMonths`는 3·5(value 4)·6·7·9·10월만 있어 '2026' 카테고리에서 수능을 고를 수 없습니다.
- **ExamSearchPanel**(`src/kit/exam-search/ExamSearchPanel.tsx`)의 `this_year` 모드는 `thisMonths`를 시행월로 쓰고, preset이 없으면 10월을 기본 선택합니다(42행).
- **ExamSearchQuery**(`src/kit/exam-search/query.ts`)의 `buildThisYearQuery`는 연도를 2026으로 고정합니다.
- 같은 패널을 **ResearchPanel**(`src/kit/research/ResearchPanel.tsx`)과 **WelcomeScreen**(`app/welcome.tsx`)이 사용합니다.

## 범위
### 하는 것
- `thisMonths` 끝에 `{ label: '수능', value: 11 }` 추가
- `this_year` 모드의 preset 없는 기본 선택 시행월을 `[10]`에서 `[11]`로 변경

### 하지 않는 것
- 문제 데이터 입력, Redis 적재, 서버 변경
- `PRE_EXAMS`, `PRE_EXAMS_ASSETS`의 연도 목록에 2026 추가
- `buildThisYearQuery`의 시행월 미선택 기본값 `[6]` 변경
- 에이전트가 넘기는 preset(mockAgent의 `months: [10]` 포함) 변경
- `thisMonths`의 기존 항목(`5월`의 value 4 포함) 변경

## 변경할 동작
1. '2026' 카테고리의 시행월에 `수능`이 10월 뒤에 표시됩니다(로그인 ResearchPanel, 비로그인 WelcomeScreen 모두).
2. preset 없이 `this_year` 패널을 열면 `수능`이 선택되어 있습니다.
3. `수능`으로 '가자!!!'를 누르면 `onSubmit` 쿼리가 `years: [2026], months: [11]`입니다.
4. preset의 `months`가 있으면 기존처럼 preset을 따릅니다.

## API 계약
기존 계약을 그대로 사용하며 변경은 없습니다.
- 로그인: `POST {CACHE_URL}/api/search2`, 본문 `{ queryType: 'selection', major, years: [2026], months: [11], numbers: [...], studyType: 'MATH_DETAILED_PRE_EXAMS' }`, 응답 `{ data: { result: Unit[] } }`
- 비로그인: `GET {CACHE_URL}/pre-exams/{major}/2026/11`, 응답 `{ data: { result: ... } }`(기존 `public-questions` 처리 유지)
- 두 경로 모두 Redis 해시 `math-month-{major}-2026-11`을 읽습니다.

## 수용 기준
- [ ] `thisMonths`의 마지막 항목이 `{ label: '수능', value: 11 }`이고 기존 6개 항목의 순서와 값은 그대로이다.
- [ ] `ExamSearchPanel mode="this_year"`를 preset 없이 렌더링하면 시행월 `수능` 칩이 선택 상태이고 `10월` 칩은 선택 상태가 아니다.
- [ ] 위 상태에서 '가자!!!'를 누르면 `onSubmit`이 `years: [2026]`, `months: [11]`을 포함한 쿼리로 호출된다.
- [ ] `ExamSearchPanel mode="this_year" preset={{ months: [10] }}`을 렌더링하면 `10월`이 선택되고 `수능`은 선택되지 않는다.
- [ ] `buildThisYearQuery({ subject: 'CALCULUS', months: [], numbers: [] })`의 `months`는 계속 `[6]`이다.
- [ ] `pre_exam` 모드의 연도 선택지와 기본 선택(시행월 수능, 현행 과목 2025년)은 변경 전과 같다.
- [ ] 위 동작을 검증하는 테스트가 `__tests__/examSearchPanel.test.tsx`에 추가되어 있다.
- [ ] 프로젝트의 jest 테스트와 타입 검사가 통과한다.

## 가정
- 카드의 '2026년도 수능'은 2026년 11월 시행 시험이며 `year=2026, month=11`로 저장되어 있다.
- 수능이 올해의 최신 시험이므로 `this_year` 패널의 기본 선택을 수능으로 바꾼다.
- 운영 Redis 적재 여부는 이 작업의 수용 기준에 넣지 않는다.

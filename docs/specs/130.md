## 배경과 목적
학생 앱의 실황 수업 화면에는 수업 시작시각이 없습니다. 서버가 관리하는 최초 On Air 시각을 표시해, 학생이 언제 들어와도 같은 시작시각을 보게 합니다.

## 범위
### 하는 것
- 시작시각 표시 컴포넌트를 추가하고 다음 화면에 넣습니다.
  - **TopicLiveClassScreen**: `app/topic-live-class.tsx`
  - **HotlineClassScreen**: `app/hotline-class.tsx`

### 하지 않는 것
- 경과시간 표시.
- 수업 메시지 처리, 캔버스, 퀴즈, **LiveClassWaiting**(`src/kit/live-class/LiveClassWaiting.tsx`) 동작 변경.

## 변경할 동작
1. `src/api/graphql/queries/topic.ts`에 `LIVE_CLASS_CLOCK`, `src/api/graphql/subscriptions.ts`에 `LIVE_CLASS_CLOCK_TICK`을 추가합니다(기존 export 경로를 따릅니다). 선택 필드는 `classType classKey startedAt elapsedMinutes serverTime`입니다.
2. `src/kit/live-class/LiveClassStartTime.tsx`를 추가합니다. props는 `{ classType: 'TOPIC' | 'HOTLINE'; classKey: string; active: boolean }`입니다.
   - `active`가 true가 될 때마다 `liveClassClock`을 `fetchPolicy: 'network-only'`로 조회합니다.
   - `active`인 동안 `liveClassClockTick`을 구독합니다(`skip: !active || !classKey`).
   - 가장 최근에 받은 값의 `startedAt`을 사용합니다. 구독으로 `startedAt: null`을 받으면 표시를 비웁니다.
   - `수업 시작 HH:mm`(기기 현지 시각, 24시간제)으로 표시하고, 값이 없으면 `수업 시작 --:--`로 표시합니다.
   - 최상위 요소에 `testID="live-class-start-time"`을 둡니다.
3. 시각 포맷은 순수 함수 `formatStartTime(startedAt)`으로 분리합니다(`src/kit/live-class/formatStartTime.ts`). null, 빈 문자열, 숫자가 아닌 값은 `--:--`를 반환합니다.
4. 두 화면에서 `savedMessage` 텍스트와 시작시각을 절대 위치의 한 가로줄(top 8, left 12, zIndex 10)에 함께 놓습니다. `savedMessage`의 글자 스타일은 유지합니다. props는 토픽 화면 `classType='TOPIC' classKey={String(topicId)} active={isFocused}`, 핫라인 화면 `classType='HOTLINE' classKey={tutorId} active={isFocused}`입니다.

## API 계약
```graphql
type LiveClassClock {
  classType: String!   # TOPIC | HOTLINE
  classKey: String!    # TOPIC: topicId, HOTLINE: tutorId
  startedAt: String    # 최초 On Air epoch ms 문자열. 진행 중이 아니면 null
  elapsedMinutes: Int  # floor((serverTime-startedAt)/60000). startedAt이 null이면 null
  serverTime: String!  # 서버 현재 epoch ms 문자열
}
Query:        liveClassClock(classType: String!, classKey: String!): LiveClassClock
Subscription: liveClassClockTick(classType: String!, classKey: String!): LiveClassClock
```
- `liveClassClockTick`은 진행 중 약 60초마다, 최초 On Air 직후, 강의 종료 직후(`startedAt: null`)에 발행됩니다.

## 수용 기준
- 토픽 실황과 핫라인 수업 화면에 `live-class-start-time` 요소가 표시됩니다.
- 토픽 화면은 `classType: 'TOPIC'`, `classKey: String(topicId)`로, 핫라인 화면은 `classType: 'HOTLINE'`, `classKey: tutorId`로 조회하고 구독합니다.
- `startedAt`이 있으면 `수업 시작 HH:mm`으로 표시되고, 없으면 `수업 시작 --:--`로 표시됩니다.
- 화면에 머무는 동안 최초 On Air가 일어나면 다시 들어오지 않아도 시작시각이 표시됩니다.
- 수업 중 화면을 나갔다 들어오거나 앱을 다시 켜도 표시되는 시작시각이 같습니다.
- 화면이 포커스를 잃으면 시계 구독이 해제되고, 다시 포커스되면 조회와 구독이 재개됩니다.
- 강의 종료 메시지(`startedAt: null`)를 받으면 `수업 시작 --:--`로 바뀝니다.
- 시계 조회나 구독이 실패해도 캔버스와 수업 메시지 처리는 계속 동작합니다.
- `savedMessage`가 계속 표시되고 시작시각과 겹치지 않습니다.
- `formatStartTime`과 표시 컴포넌트의 jest 테스트를 포함해 `npm test`가 통과합니다.

## 가정
- 요구사항의 문구대로 학생 화면에는 시작시각만 표시하고 경과시간은 표시하지 않습니다.
- 수업 전 대기 화면(`LiveClassWaiting`)은 전체를 덮는 기존 동작을 유지하므로 그동안 시작시각은 가려집니다.

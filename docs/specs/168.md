# 실황 수업 종료 모달 (student-app)

## 배경과 목적
선생님이 '강의 종료'를 누르면 graphql-server가 실황 수업 구독으로 `{ action: 'LIVE_CLASS_CLOSED' }` guide를 보냅니다. 학생 앱은 이 guide를 받으면 '수업이 종료되었습니다' 문구와 '확인' 버튼만 있는 모달을 보여 줍니다. '확인'을 누르면 캔버스 화면을 나갑니다. 나가는 동작은 화면의 '나가기' 버튼과 같은 `goBack`입니다.

대상 화면은 둘입니다(docs/COMPONENTS.md 기준).
- **HotlineClassScreen**: `app/hotline-class.tsx` (`/hotline-class`)
- **TopicLiveClassScreen**: `app/topic-live-class.tsx` (`/topic-live-class`)

## 범위
### 하는 것
- 두 Screen의 `useSubscription` `onData`에서 `guide.action === LIVE_CLASS_CLOSED`를 quiz/imageQuiz 분기보다 먼저 처리합니다.
- `src/kit/live-class/constants.ts`에 `export const LIVE_CLASS_CLOSED = 'LIVE_CLASS_CLOSED'`를 추가합니다.
- 종료 모달 컴포넌트를 새로 만듭니다. 예: `src/kit/live-class/LiveClassClosedModal.tsx`. docs/COMPONENTS.md에 `LiveClassClosedModal` 항목을 추가합니다.

### 하지 않는 것
- 캔버스 패널(HotlineClassCanvas `src/kit/canvas/note-canvas/hotline-class-canvas.tsx`, TopicLiveCanvas `src/kit/canvas/note-canvas/topic-live-canvas.tsx`)의 `onReceiveGuide`는 바꾸지 않습니다.
- 다른 guide 처리, 마지막 메시지 조회, 재연결 복구(`recoverLivePosition`)는 바꾸지 않습니다.
- '나가기' 버튼 자체의 동작은 바꾸지 않습니다(카드 #164의 범위).

## 변경할 동작
1. 구독으로 받은 guide의 action이 `LIVE_CLASS_CLOSED`이면 다음처럼 처리하고 return합니다.
   - 종료 모달 표시 상태를 true로 바꿉니다. 이미 true면 그대로 둡니다(중복 수신에 대한 멱등 처리).
   - 이 guide는 `panelRef.current.onReceiveGuide`로 넘기지 않습니다.
   - `setLiveState`, `lastAppliedPositionRef`, `setSavedMessage`도 바꾸지 않습니다.
2. 종료 모달은 React Native `Modal`(transparent, fade)입니다.
   - 본문은 '수업이 종료되었습니다'입니다.
   - 버튼은 '확인' 하나만 있습니다.
   - 배경을 눌러도 닫히지 않습니다. Android 뒤로가기(`onRequestClose`)는 '확인'과 같게 처리합니다.
   - QuizResponseModal보다 위에 보이도록, 열릴 때 `setLiveQuiz(null)`로 퀴즈 모달을 닫습니다.
3. '확인'을 누르면 모달을 닫고 그 화면의 `goBack()`을 부릅니다. `goBack`은 `router.canGoBack() ? router.back() : router.replace('/')`입니다.

## API 계약
받는 쪽입니다(graphql-server가 보냄). 스키마 변경은 없습니다.
- Hotline: `subscription newOnlineClassMessage(tutorId: String!)`의 payload `{ id: "closed-<epochMs>", content: "{\"action\":\"LIVE_CLASS_CLOSED\",\"tutorId\":\"<tutorId>\"}", tutorId, createdAt }`
- Topic: `subscription liveTopicClassMessage(topicId: Int!)`의 payload `{ id: "closed-<epochMs>", content: "{\"action\":\"LIVE_CLASS_CLOSED\",\"topicId\":<topicId>}", topicId, createdAt }`
- topic 수업에서는 같은 종료 메시지가 두 번 올 수 있습니다.

## 수용 기준
- `src/kit/live-class/constants.ts`가 `LIVE_CLASS_CLOSED = 'LIVE_CLASS_CLOSED'`를 export한다.
- HotlineClassScreen이 구독으로 content `{"action":"LIVE_CLASS_CLOSED","tutorId":"t1"}`를 받으면 '수업이 종료되었습니다' 문구와 '확인' 버튼이 있는 모달이 보인다.
- TopicLiveClassScreen이 구독으로 content `{"action":"LIVE_CLASS_CLOSED","topicId":5}`를 받으면 같은 모달이 보인다.
- 모달에 있는 버튼은 '확인' 하나뿐이다.
- 모달 배경을 눌러도 닫히지 않는다.
- LIVE_CLASS_CLOSED guide를 받아도 패널의 `onReceiveGuide`가 호출되지 않는다.
- LIVE_CLASS_CLOSED를 두 번 받아도 모달은 하나만 보인다.
- 퀴즈 모달이 열려 있을 때 LIVE_CLASS_CLOSED를 받으면 퀴즈 모달이 닫히고 종료 모달이 보인다.
- '확인'을 누르면 모달이 닫힌다. `router.canGoBack()`이 true면 `router.back()`이, false면 `router.replace('/')`가 호출된다.
- Android 뒤로가기(`onRequestClose`)도 '확인'과 같은 결과를 낸다.
- quiz, imageQuiz, units, CLASS_ON_AIR 등 기존 처리와 관련 테스트(liveClassWaiting.test.tsx, classOnAir*.test 등)가 변경 없이 통과한다.
- 위 동작을 검증하는 테스트가 추가되어 통과한다.

## 가정
- '캔버스 스크린 나가기'는 두 화면에 이미 있는 `goBack`('나가기' 버튼과 같은 함수)을 부르는 것으로 정했습니다.
- 모달은 공용 UI 컴포넌트를 쓰지 않고 RN `Modal`로 새로 만듭니다.

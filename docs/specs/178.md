# 실황 수업 종료 메시지의 정리 내용을 학습장 시트에 반영 (student-app)

## 배경과 목적
학생 앱의 두 화면이 LIVE_CLASS_CLOSED를 받으면 `markClassClosed()`를 부릅니다. 화면을 나갈 때는 `openLiveStudyNoteOnLeave`가 학습장 시트(`study_note`, mode 'live')를 엽니다. 두 화면은 docs/COMPONENTS.md 기준 **HotlineClassScreen**(`app/hotline-class.tsx`)과 **TopicLiveClassScreen**(`app/topic-live-class.tsx`)입니다. 시트 안의 **StudyNoteForm**(`src/kit/study-note/StudyNoteForm.tsx`)이 보여 주는 정보는 다음과 같습니다.
- '선생님 정리'는 서버 노트의 `tutorDescription`입니다.
- 개념과 퀴즈는 활동 기록(Activities)과 `fetchSentQuizzes`로 채웁니다.

이번에 graphql-server가 종료 메시지에 description, concepts, quizzes를 함께 보냅니다. 이 값을 학습장 시트에 반영합니다.

## 범위
### 하는 것
- 종료 guide에서 정리 내용을 꺼내는 순수 함수 `pickLiveClassClosing(guide)`를 만듭니다. 위치는 예를 들어 `src/kit/live-class/closing.ts`입니다.
- 두 화면의 LIVE_CLASS_CLOSED 분기에서 `markClassClosed(pickLiveClassClosing(guide))`를 부릅니다.
- `useSolveFinished`(`src/host/useSolveFinished.ts`)는 받은 closing을 ref에 둡니다. 언마운트할 때 `openLiveStudyNoteOnLeave`에 `closing`으로 넘깁니다.
- `openLiveStudyNoteOnLeave`(`src/host/liveStudyNoteOnLeave.ts`)는 closing의 개념과 퀴즈를 활동 기록에 합칩니다. 시트 props에 `tutorDescription`과 `quizContents`를 더합니다.
- `src/host/registry.ts`의 `study_note` propsSchema와 StudyNoteForm props에 `tutorDescription`, `quizContents`를 추가합니다.

### 하지 않는 것
- 종료 모달(LiveClassClosedModal)의 UI와 '확인' 동작은 바꾸지 않습니다.
- 수업 종료 전에 나가는 경우의 동작은 바꾸지 않습니다.
- 학습장 저장 API와 형식(persistNote, toInput)은 바꾸지 않습니다. 활동 기록이 저장 때 함께 가는 동작은 지금 코드 그대로입니다.
- self 모드 양식은 바꾸지 않습니다.

## 변경할 동작
1. `pickLiveClassClosing(guide)`
   - guide.action이 LIVE_CLASS_CLOSED가 아니면 null입니다.
   - 맞으면 `{ description, concepts, quizzes }`를 돌려줍니다.
     - description은 문자열이면 그 값, 아니면 `''`입니다.
     - concepts는 `{id: 양의 정수, title: 비지 않은 문자열}`만 남기고 id 중복을 없앱니다.
     - quizzes는 `{quizId: 양의 정수, content: 문자열}`만 남기고 quizId 중복을 없앱니다.
     - 배열이 아니면 각각 []입니다.
   - 세 필드가 모두 비었으면(description `''`, 두 배열 비어 있음) null을 돌려줍니다.
2. `markClassClosed(closing?)`: 지금처럼 closed ref를 true로 합니다. closing이 null이 아니면 closing ref에 저장합니다. 여러 번 받으면 마지막으로 받은 null 아닌 값을 씁니다.
3. `openLiveStudyNoteOnLeave({ ..., closing })`에서 task를 확보한 뒤 다음을 합니다.
   - closing이 있으면 `{ v:1, concepts: closing.concepts, quizIds: closing.quizzes.map(q=>q.quizId) }`를 이번 방문 activity와 함께 `appendActivity`로 합칩니다.
   - `showSheet('study_note', { taskId, mode:'live', title, ...(closing.description ? { tutorDescription: closing.description } : {}), ...(closing.quizzes.length ? { quizContents: closing.quizzes } : {}) })`를 부릅니다. closing이 없으면 지금과 같은 props입니다.
4. `study_note` propsSchema에 `tutorDescription: z.string().max(2000).optional()`와 `quizContents: z.array(z.object({ quizId: z.number().int(), content: z.string() })).max(50).optional()`을 추가합니다. 시트 위젯은 두 props를 StudyNoteForm에 그대로 넘깁니다.
5. StudyNoteForm(mode 'live')
   - '선생님 정리' 상자는 `existing?.tutorDescription || tutorDescription || '선생님 정리가 아직 없어요'`를 보여 줍니다.
   - `quizContents` prop이 있으면 퀴즈 본문 Map의 처음 값으로 씁니다. `fetchSentQuizzes` 결과는 Map에 없는 quizId만 더합니다.
   - '조회 내용'(개념)과 Quiz 영역은 지금처럼 활동 기록에서 그립니다. 3번에서 합친 개념과 퀴즈가 여기에 보입니다.
6. docs/COMPONENTS.md에 `pickLiveClassClosing`의 위치를 적습니다.

## API 계약
받는 쪽입니다. 스키마 변경은 없습니다.
- Hotline `newOnlineClassMessage(tutorId)`의 content: `{"action":"LIVE_CLASS_CLOSED","tutorId":"t1","lessonNoteId":123,"description":"...","concepts":[{"id":7,"title":"등차수열"}],"quizzes":[{"quizId":9,"content":"..."}]}`
- Topic `liveTopicClassMessage(topicId)`의 content: `{"action":"LIVE_CLASS_CLOSED","topicId":5,"lessonNoteId":123,"description":"...","concepts":[...],"quizzes":[...]}`
- lessonNoteId, description, concepts, quizzes는 없을 수 있습니다(예전 서버, 또는 tutor-web이 closing을 보내지 않은 경우). topic 수업에서는 같은 메시지가 두 번 올 수 있습니다.

## 수용 기준
- `pickLiveClassClosing({action:'quiz'})`와 `pickLiveClassClosing({action:'LIVE_CLASS_CLOSED',tutorId:'t1'})`가 null을 돌려준다.
- `pickLiveClassClosing({action:'LIVE_CLASS_CLOSED',description:'d',concepts:[{id:7,title:'A'},{id:7,title:'B'},{id:0,title:'C'}],quizzes:[{quizId:9,content:'q'},{quizId:'x',content:'y'}]})`가 `{description:'d',concepts:[{id:7,title:'A'}],quizzes:[{quizId:9,content:'q'}]}`를 돌려준다.
- `openLiveStudyNoteOnLeave`에 `acted:true`, taskId 3, closing `{description:'d',concepts:[{id:7,title:'A'}],quizzes:[{quizId:9,content:'q'}]}`를 넘긴 경우를 확인한다. store의 `agent:studyNoteActivity:3`에 concept 7과 quizId 9가 들어간다. `showSheet('study_note', {taskId:3, mode:'live', title, tutorDescription:'d', quizContents:[{quizId:9,content:'q'}]})`가 한 번 호출된다.
- closing이 null이면 `showSheet`의 props는 `{taskId, mode:'live', title}`로 지금과 같다.
- HotlineClassScreen이 정리 필드가 담긴 LIVE_CLASS_CLOSED를 받은 뒤 '확인'으로 언마운트하면, 학습장 시트가 위 props(tutorDescription, quizContents)로 열린다. TopicLiveClassScreen도 같다.
- LIVE_CLASS_CLOSED를 두 번 받아도 시트는 한 번만 열린다.
- StudyNoteForm(mode 'live')에 `tutorDescription:'d'`를 넘기고 서버 노트의 tutorDescription이 비어 있으면, '선생님 정리' 상자에 'd'가 보인다. 서버 노트에 tutorDescription이 있으면 그 값이 보인다.
- StudyNoteForm(mode 'live')에 `quizContents:[{quizId:9,content:'q'}]`를 넘기고 활동 기록에 quizId 9가 있으면, Quiz 영역(`study-note-quiz-section`)에 'q'가 보인다. `fetchSentQuizzes`가 실패해도 그대로 보인다.
- 활동 기록에 합친 개념은 '조회 내용' 영역(`study-note-concepts-section`)과 추천 칩에 보이고, 저장할 때 `activities`에 들어간다.
- 기존 테스트(liveClassClosed.test.tsx, liveClassClosedSheet.test.tsx 등)가 통과하고, `npx jest`와 `npx tsc --noEmit`이 통과한다.

## 가정
- '학습장 작성에 반영'은 종료 뒤 여는 학습장 시트에 세 가지를 보이는 것으로 보았습니다.
  - description은 '선생님 정리'에 보입니다. 학생 메모에 자동으로 채우지는 않습니다.
  - 개념은 조회 내용과 추천 칩에 보이고, 퀴즈는 Quiz 영역에 보입니다.
- 서버 노트의 tutorDescription이 있으면 그것을 먼저 씁니다. 종료 메시지 값은 서버 값이 아직 없을 때 쓰는 대체값입니다.
- 종료 메시지의 개념과 퀴즈는 학생이 직접 조회하거나 받지 않았어도 이번 수업 기록으로 보고 활동 기록에 합칩니다.
